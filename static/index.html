A BOTTLENECK BEYOND THE CODE

7,168 tracking entries. A hard-to-see ceiling.

The first 10,000-connection attempt stalled below the target. Kernel logs exposed a full Linux connection-tracking table. Raising its limit to 65,536 enabled a subsequent run to reach 10,000 benchmark sockets. Debugging the host mattered as much as writing the server.

I/O MODEL

Wait on events, not threads.

One selector watches non-blocking sockets. The event loop handles ready connections while each client keeps its own input and output buffers.

HTTP LIFECYCLE

Keep the connection useful.

HTTP/1.0 and HTTP/1.1 handling, persistent connections, request bodies, partial writes, and graceful shutdown—all implemented explicitly.

GUARDRAILS

Bound what a client can ask.

Header and body limits, idle timeouts, a connection cap, and strict framing checks. Socket-level regression tests cover core behaviors.
